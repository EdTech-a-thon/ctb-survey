Quick guide

Template syntax

  1. 01
    Reusable values

    Use R(1), R(2), and so on. Each value stays consistent within a question.

  2. 02
    Fractions

    Use two slashes, such as (x + 1) // 2.

  3. 03
    Square roots

    Use sqrt(R(1)) or \sqrt{R(1)}.

Teacher tip Add a perfect square rule when using square roots to keep answers tidy.
